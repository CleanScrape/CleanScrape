# CleanScrape

We build web data tools on Apify, with clear inputs, structured exports and practical documentation.

This GitHub account is where we share agent skills and examples for using those tools. The commercial scrapers stay on Apify; the public guides help you get from an export to a useful answer.

## Start here

[Agent skills](https://github.com/CleanScrape/agent-skills) covers all eight CleanScrape Actors, from app-review comparison and search trends to product, news, event and hotel research. You can work with existing exports without starting a new scrape. Fresh collection uses your own Apify account and is billed at the Actor's current rates.

[Browse our Actors](https://apify.com/cleanscrape) for the supported sources, examples and pricing.

[Watch a demo](https://www.youtube.com/@CleanScrapeTools) or [read a walkthrough](https://dev.to/cleanscrape).

## Questions or feedback

For a problem with a skill, open an issue in its repository. For an Actor run, use the Actor's Issues tab or contact [contact.cleanscrape@gmail.com](mailto:contact.cleanscrape@gmail.com).

Tell us what you expected and what happened. Please leave out tokens and private customer data.
