# CleanScrape

We build web data tools on Apify, with clear inputs, structured exports and practical documentation.

This GitHub account is where we share agent skills and examples for using those tools. The commercial scrapers stay on Apify; the public guides help you get from an export to a useful answer.

## Start here

[Agent skills](https://github.com/CleanScrape/agent-skills) covers all thirteen CleanScrape Actors, from app-review comparison and search trends to product, news, event, hotel, Threads post, Likee comment, tennis match, Bilibili video and Google Jobs research. You can work with existing exports without starting a new scrape. Fresh collection uses your own Apify account and is billed at the Actor's current rates.

[Browse our Actors](https://apify.com/cleanscrape) for the supported sources, examples and pricing.

## Python libraries

For scripts that broke when an old library stopped working:

- [trendreq](https://github.com/CleanScrape/trendreq): a drop-in replacement for pytrends. Same `TrendReq` API, without 429 errors.
- [app-store-reviews](https://github.com/CleanScrape/app-store-reviews): a drop-in replacement for app-store-scraper, plus Google Play reviews.

Both run on our Apify Actors, so there's no proxy setup on your side.

[Watch a demo](https://www.youtube.com/@CleanScrapeTools) or [read a walkthrough](https://dev.to/cleanscrape).
